# AGENTS.md — VPNGuard 3.0 Repository Guide for AI Agents

This file is the primary operational reference for AI coding agents working in `~/Desktop/Business/Кодинг/VPNGuard` (GitHub: `RadmirMain/vpnguard`).
For user setup and CLI reference see [README.md](README.md). For deep architectural diagrams and PF/sing-box specifications see [ARCHITECTURE.md](ARCHITECTURE.md).

## 1. Repository Layout
- `VERSION` / `LICENSE` — Single source of truth for app version (`CFBundleShortVersionString`, currently `3.0.1`) and MIT license.
- `.github/workflows/release.yml` — CI/CD workflow on `macos-15`: installs `sing-box` + `xray` via Homebrew, runs Swift & offline Python unit tests, builds `VPNGuard.app` with bundled `backend/` (excluding large `vpnguard-xray` & `bin/vpnguard-exec` from `bin/`, compiling `libexec/vpnguard-exec`), packages via `ditto`, computes `.sha256`, signs with Ed25519 (`RELEASE_SIGNING_PRIVATE_KEY` secret -> `.sig`), and publishes to GitHub Releases.
- `src/vpnguard.py` — Main Python 3 CLI & privileged control plane (installed to `/usr/local/share/vpnguard/src/vpnguard.py` and invoked via `/usr/local/bin/vpnguard`).
- `src/vpnguard_exec.c` — C setuid-root sandbox launcher (`04750 root:admin`, GID `888`, compiled by `install.sh` / bundled into `Contents/Resources/backend/libexec/vpnguard-exec`).
- `src/browser/vpnguard-browser` — Hardened Chromium launcher inside GID `888`.
- `src/pf/` — PF anchor rules (`vpnguard.pf.conf`), boot script (`vpnguard-pf-boot.sh`), and LaunchDaemon plist.
- `src/singbox/`, `src/xray/` — LaunchDaemon plists and `src/xray/xray.json.example` template config (dynamic `sing-box.json` is generated by `vpnguard.py` and `install.sh`).
- `app/VPNGuardApp/` — SwiftUI macOS 14+ application (`Package.swift`, `Sources/VPNGuardApp/`, `Tests/VPNGuardAppTests/`, `build_app.sh`).
- `install.sh` / `uninstall.sh` / `update.sh` — System installer (resolves or auto-installs `xray` + `sing-box`), clean uninstaller, and two-stage updater.
- `tests/` — Python `unittest` suite (`test_pf_syntax.py`, `test_singbox_config.py`, `test_vless_parser.py`, `test_logs_and_routing.py`, `test_pause_resume.py`, `test_server_ping.py`, plus live-daemon `test_launcher.py` & `test_proxy.py`) and manual live checks (`live_test.sh`).

## 2. Hard Invariants (Never Violate)
1. **Fail-Closed Routing & Domain Specificity**:
   - `sing-box.json` MUST keep `route.final == "xray-upstream"`; never add an unconditional `direct` catch-all rule.
   - `xray.json` MUST NOT contain `freedom` or `direct` outbounds.
   - Local listeners are strictly loopback-only (`127.0.0.1:18088`, `127.0.0.1:18089`, `127.0.0.1:9090`).
   - `dns.rules` and `route.rules` MUST sort domain rules by descending label count (most specific first) and group only adjacent same-action entries so broad suffixes never shadow narrower subdomains.
2. **Desired State, Concurrency Locking & Timeouts**:
   - `cmd_on` / `cmd_off` MUST persist `/var/db/vpnguard/desired_state` (`on` written strictly after config validation and strictly before `vpnguard-pf-boot.sh on`) and toggle `launchctl enable/disable` for `com.vpnguard.pf` & `com.vpnguard.singbox` so reboot respects `off`.
   - `vpnguard-pf-boot.sh` MUST reuse `pf.token` only when `pfctl -s info` shows `Status: Enabled`, flush `vpnguard/egress` & `vpnguard` **before** `pfctl -X` + `rm -f pf.token` on `off`, and sync DNS on cold boot when `desired_state == on`.
   - Mutating CLI commands (`on`, `off`, `pause`, `resume-if-expired`, `rules apply`, `server activate`, `server update`) and `pause-watcher` resume phase MUST run under re-entrant non-blocking `acquire_state_lock()` (`fcntl.flock`, `/var/run/vpnguard/state.lock`, 15s timeout).
   - All `subprocess.run()` calls MUST have bounded `timeout=`; `_run_in_gid890_worker()` MUST enforce `select.select()` timeout with `SIGKILL` + `os.waitpid(pid, 0)`.
3. **Strict `sudoers` (Zero Wildcards) & Log Safety**:
   - `/etc/sudoers.d/vpnguard` MUST contain only exact-match commands (zero `*`).
   - Mutating inputs (`rules apply`, `server import-vless`, `server activate`, `server delete`, `server update`) MUST use `--stdin` with `read_stdin_bounded()`.
   - `vpnguard logs --json` MUST accept no arbitrary file/line arguments, MUST tail via binary reverse `seek` (`_tail_file_lines()`), and MUST pass outputs through `redact_sensitive_text()` (`vless://`, `trojan://`, `ss://`, `vmess://`, UUIDs, Reality keys, `Bearer`, JSON `password`/`psk`/`privateKey`/`token`/`auth`, query params).
   - Log rotation (`rotate_log_if_needed()`, 8 MiB -> `.1`) MUST happen strictly before `launchctl bootstrap/kickstart` / `vpnguard-pf-boot.sh`; Xray uses launchd `StandardOutPath`/`StandardErrorPath` without duplicate `log.error` file writes.
4. **Triple-GID Isolation & Bypass Workers**:
   - `GID 888` (`vpnguard`): sandboxed CLI/browser jail (`vpnguard-exec` explicitly rejects `real_uid == 0`).
   - `GID 889` (`_vpnguard_proxy`): headless Xray daemon; outbound allowed only to `vpnguard/egress`.
   - `GID 890` (`vpnguard-tun`): headless `sing-box` daemon (`utun99`); PF allows IPv4 TCP/UDP egress.
   - Any direct bypass probe while `utun99` is active (`server ping`, `server sync-pf` UDP DNS, `activate_server` domain resolution) MUST use `_run_in_gid890_worker()` (`setgroups([890])` -> `setgid(890)` -> `setuid(nobody)` in that exact order) with `IP_BOUND_IF = 25` on the physical interface from `netstat -rn -f inet`.
   - `activate_server()` skips `launchctl kickstart` when VPN is OFF and verifies `18088`, `18089`, and `utun99` with full config + PF + daemon rollback when ON.
5. **macOS App Signing, Releases & UI Behavior**:
   - `VPNGuard.app` uses ad-hoc signing (`codesign --force --deep --sign -`).
   - Write `Contents/Resources/frontend.sha256`, bundle `Contents/Resources/backend/` (omitting `vpnguard-xray` & `bin/vpnguard-exec`, including `libexec/vpnguard-exec` + `backend.sha256` whose hash excludes `vpnguard-xray` and `vpnguard-exec`), set `CFBundleShortVersionString` from `VERSION`, and run `xattr -cr` **strictly before** `codesign`. Never mutate bundle files or `Info.plist` after signing.
   - `GitHubReleaseUpdater` verifies Ed25519 `.sig` against its embedded public key and `.sha256` before extraction, stages onto `/Applications`, and relaunches via `nohup` (logging to `~/Library/Logs/VPNGuard/github-update-relaunch.log`) without `open -n`.
   - Store mutable user preferences (`sourceRepoPath`, `autoFailoverEnabled`) in `UserDefaults`, never `Info.plist`.
   - Login autostart uses solely `~/Library/LaunchAgents/com.vpnguard.app.plist` (never `SMAppService` or `System Events` Login Items).
   - Launch `vpnguard-browser` directly as the console user (never via `sudo`) and redirect stdout/stderr to `~/Library/Logs/VPNGuard/browser-launch.log` (never leave an undrained `Pipe()` on Chromium).
   - UI state transitions propagate `stateEpoch`, map armed PF with stopped tunnel to `ProtectionState.tunnelRecovering`, resume `CLIExecutor` immediately on timeout, and drive active pause countdowns exclusively via conditional `TimelineView(.periodic)`.
6. **Installer & Updater Safety**:
   - `install.sh` and `uninstall.sh` MUST resolve `TARGET_USER` via `SUDO_USER` -> `stat -f '%Su' /dev/console` -> `id -un` (because `osascript ... with administrator privileges` leaves `SUDO_USER` empty); `install.sh` must skip arming PF if `xray.json` contains `REPLACE_WITH_UUID` or existing `desired_state == off`.
   - `update.sh` runs `swift build` as the normal user in `/tmp`, elevates via Touch ID only when `backend.sha256` changes, and uses `LC_ALL=C sort -z` with `find ... -print0 | xargs -0`.
   - Wi-Fi pause timer uses wall-clock `/var/run/vpnguard/pause_until` + single `/var/run/vpnguard/pause_watcher.pid` (cleaned in `finally` under lock), cleared on `vpnguard on` / `vpnguard off`.
7. **No Real Secrets in Git**:
   - Never commit real `vless://` URIs, UUIDs, Reality keys, `api_secret`, or production relay IPs/domains. Use RFC 5737 test IPs (`203.0.113.0/24`), dummy UUIDs, and `example.com` in tests and `*.example.json`.

## 3. Standard Verification Commands
Run after any code change before committing:
```bash
python3 -m py_compile src/vpnguard.py
bash -n install.sh uninstall.sh update.sh src/pf/vpnguard-pf-boot.sh src/browser/vpnguard-browser app/VPNGuardApp/build_app.sh tests/live_test.sh
pfctl -n -v -f src/pf/vpnguard.pf.conf
python3 -m unittest discover -s tests -v
swift test --package-path app/VPNGuardApp
swift build --package-path app/VPNGuardApp -c release --arch arm64
```
Live check on a configured host:
```bash
./update.sh --check --no-pull
sudo -n /usr/local/bin/vpnguard test --json
```
